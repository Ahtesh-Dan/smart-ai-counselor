An AI-powered admission assistant designed to help prospective students with inquiries, course details, and department routing for AKS University.

* **Python:** Core scripting and automation
* **Gradio:** Interactive web interface
* **Google Gemini AI:** Intelligent conversational engine
* **Google Cloud Platform (GCP):** Cloud environment and deployment
* **Docker:** Containerization 

* Automated student query handling and guidance.
* Secure configuration (API keys protected).
* Cloud-ready architecture.
